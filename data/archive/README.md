# Older firm tables

These files were folded into `processed/firms.csv` or replaced by a later table. They are kept so the earlier counts and the original company file can still be checked.

| File | What it was |
| --- | --- |
| `firm_info.csv` | The added company file, including the older list counts. An applicant list and the later ranking of the same school were both counted. |
| `firm_crosswalk.csv` | Spelling map for that 144-firm list. The current map is `processed/firm_alias_audit.csv`. |
| `firm_win_stats.csv` | Completed-ranking record before those columns were added to `processed/firms.csv`. |
| `source_manifest.csv` | A copy of `manifests/sources.csv`. |
